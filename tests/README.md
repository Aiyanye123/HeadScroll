# 人工检查

在 Windows 运行 `python src\main.py`，分别使用浏览器阅读页和实际目标阅读程序检查以下流程。

- 语音模式说“左”“右”“暂停”“继续”，确认前台程序收到相应翻页，暂停后不翻页。关闭完整面板后检查 compact 状态窗，再恢复完整面板。
- 头部模式完成抬头、自然、低头三点标定，检查上下滚动方向、自然姿势停止及进度。标定时移出摄像头范围应拒收无效样本；错误顺序应提示重做。
- 在标定采样中、步骤间和成功提示期间分别取消或关闭向导，再打开应从初始状态开始，不受前次计时器影响。
- 在语音模式运行、暂停和停止状态下分别打开设置，选择头部模式后直接校准两端范围。确认无需先保存或离开设置，校准时不会滚动或翻页，结束后恢复原运行状态；模式选择和其他未保存设置保持不变。
- 保存设置确认新范围生效；重新记录后取消设置，确认旧范围保留。关闭范围窗口、摄像头启动失败或使用 Esc 紧急停止后，检查相应状态和错误提示，紧急停止后不应自动重新启动。
- 选择指定进程目标，将鼠标和前台焦点移到其他程序，确认滚动仍只发往目标。关闭目标程序后应停止并提示错误。测试亚刻度与整格滚动在目标程序中的响应。
- 滚动时暂停、恢复、停止后重新启动，以及移开人脸后返回，确认重新触发前没有遗留滚动。托盘、完整面板和 compact 状态应与实际启停一致。
- 目标程序在前台时使用 `Ctrl+Shift+Space` 和 `Esc`，确认暂停/恢复、紧急停止在全局生效。更换冲突快捷键时应显示注册错误。
- 在中文目录启动构建产物，检查人脸模型和内置 Vosk 模型可用；退出并重启后确认用户设置持久化。

核心回归使用标准库 unittest，硬件、目标程序行为和窗口操作由上述人工检查覆盖，不运行 UI 单元测试。
